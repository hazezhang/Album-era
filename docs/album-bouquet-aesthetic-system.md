## 1. 系统定义

这套风格不是传统的“自然、浪漫、花园感”花艺，而是一种 **专辑视觉的立体转译**：把封面的颜色、明暗、构图、材质和情绪，转换成可以被手持、陈列和拍摄的花束。

核心气质：

- **编辑感**：像时装杂志、唱片封套或舞台道具，而非日常礼品花束。
- **人造感**：不掩饰染色、喷色、金属、塑料、纸张与永生材料的存在。
- **戏剧感**：高反差、深背景、明确焦点，带一点暗黑、超现实或复古未来感。
- **概念先行**：先还原作品的视觉人格，再考虑“花是否自然好看”。
- **可识别性**：即使移除专辑封面，花束仍应保留原作品的综合色彩与情绪记忆。

一句话准则：

> 不复制封面里的物体，复制封面的视觉秩序与情绪温度。

## 2. 五条最高优先级原则

### 2.1 先建立色彩层级，不平均分配颜色

每束只设一个主色世界。建议比例：

| 色彩角色 | 建议占比 | 作用 |
| --- | ---: | --- |
| 基底色 | 40%–55% | 决定第一眼的色域与整体情绪 |
| 支撑色 | 20%–30% | 丰富层次，连接基底与焦点 |
| 明暗平衡色 | 15%–25% | 提供留白、体积或暗部重量 |
| 强调色 | 5%–10% | 制造记忆点与视觉冲突 |
| 微型符号色 | 0%–3% | 对应封面中的小图形、文字或叙事线索 |

禁止把 4–6 种颜色做成面积近似的“彩虹拼盘”。颜色越多，面积差异越要明显。

### 2.2 保留一个明确冲突

每个设计至少保留一种可见张力：

- 冷色主体 + 暖色针点；
- 柔和粉色 + 大面积黑色；
- 高纯度红色 + 电光蓝；
- 植物形态 + 金属或塑料质感；
- 巨大焦点花 + 细长漂浮线条；
- 稠密花体 + 大块平整包装纸。

没有冲突，作品会退化成普通商业花束。

### 2.3 轮廓优先于花材名贵程度

远看时，应先读到一个清晰剪影。标准轮廓是：

- 上宽下窄的纵向锥形或扇形；
- 轻微不对称，重心稳定但不完全镜像；
- 1–3 条线性材料越出主体边界；
- 主花集中成焦点，不均匀散落；
- 包装形成一到三块大色面，参与构图而非仅用于包裹。

### 2.4 材质必须有软硬对照

一束中至少同时存在：

- 柔软／蓬松：绣球、芦苇、兔尾、苔藓、细叶、羽毛状材料；
- 坚硬／光滑：百合、玫瑰、马蹄莲、龟背叶、喷色叶片、金属纸；
- 平整／图形化：大张包装纸、半透明膜、欧根纱、镭射膜；
- 细线／悬垂：铁丝、藤条、垂穗、细枝、灯串。

全束都柔软会显得甜俗；全束都硬会像模型，需要用细碎肌理恢复生命感。

### 2.5 包装是“背景板”，不是边框

包装承担专辑封面的底色与版式功能。其面积可以达到正面可见面积的 25%–40%。优先使用大块、干净、略带弧度的纸面，避免多层荷叶边式包装。

## 3. 颜色策略

### 3.1 总体倾向

- 偏好 **黑底或极暗环境**，让花束像被舞台聚光灯单独照亮。
- 偏好经过设计的非自然色：黑花、银花、灰蓝、薄荷青、酒红、钴蓝、荧光绿。
- 自然绿不是默认背景色；它必须服从专辑色盘，可被压暗、偏黄、偏蓝或大量隐藏。
- 白色通常不是纯白，而是象牙白、灰白、银白或被环境色染过的冷白。
- 高饱和色宜集中使用，低饱和色宜扩大面积。

### 3.2 常用配色模型

#### A. 单色沉浸

用同一色相的明度和材质差异构建层次，例如薄荷青、暗绿、粉色。

规则：

- 至少包含 4 个明度层级；
- 用透明、哑光、绒面、亮面避免“糊成一块”；
- 可加入不超过 5% 的黑、白或互补色作为锚点。

适合：梦幻、氛围音乐、水感、朦胧记忆。

#### B. 黑色基底 + 单一亮色

黑色或近黑色占 55%–75%，以红、黄、粉或银色作为唯一强强调。

规则：

- 亮色只在 1–3 个区域出现；
- 最大亮色区必须对应主焦点；
- 避免再加入第二个同等级高纯度颜色。

适合：暗黑流行、失恋、夜晚、危险感、冷峻人物封面。

#### C. 对撞双色

使用视觉距离较大的两种色相，例如红／蓝、粉／黑、黄／钴蓝、酒红／冰蓝。

规则：

- 使用 65:35 或 75:25，不使用 50:50；
- 一色负责大体积，另一色负责主花或线条；
- 中性色只作连接，不另立主题。

适合：情绪矛盾、双人叙事、强烈流行视觉。

#### D. 低饱和植物色

苔绿、墨绿、鼠尾草、灰白、羊皮纸色为主，配少量腐叶黄、褪色蓝或肤色。

规则：

- 明度集中在中低区间；
- 依靠枝条、苔藓、褶皱纸和细叶建立细节；
- 焦点花可以接近黑色，避免田园感。

适合：独立音乐、森林、死亡与记忆、旧电影感。

#### E. 高纯度流行色块

亮绿、亮黄、粉、青蓝等高饱和颜色并置。

规则：

- 最多 3 个高纯度色；
- 必须由一种大面积包装色统一；
- 花型保持图形化、块面化，减少碎花；
- 用白、灰或透明材料留出呼吸区。

适合：流行、卡通、青春、千禧感、实验电子。

### 3.3 色盘生成流程

从封面提取颜色时，不直接采用出现频率最高的五色，而按下列角色选择：

1. **环境色**：封面最大面积背景色。
2. **主体色**：人物、标题或核心图形的主要颜色。
3. **高光色**：最亮的有效颜色。
4. **阴影色**：最深且带色相倾向的颜色。
5. **意外色**：面积很小但最有记忆度的颜色。

随后合并相近色，并将结果压缩为：

- 简单封面：3 色；
- 常规封面：4 色；
- 强概念封面：最多 5 色。

### 3.4 色彩落位规则

- 背景色 → 包装纸、体积花、整体喷色；
- 主体色 → 最大主花或中心簇群；
- 高光色 → 白花、银色材料、浅色穗材；
- 阴影色 → 深色叶材、底层填充、绑带；
- 意外色 → 单枝小花、花芯、线条、装饰物或丝带边缘。

颜色应在不同尺度重复：至少一次大面积、一次中面积、一次微小回声，但强调色可例外，只出现一次以保持突兀感。

## 4. 风格与构图特征

### 4.1 整体形态

默认采用 **正面展示型手绑花束**，不是四面观赏圆形花束。

- 高宽比：约 1.25:1 至 1.65:1；
- 花头主体占总高度约 55%–70%；
- 手柄与收口占总高度约 20%–30%；
- 包装顶部高出主体花材约 5%–20%；
- 视觉重心通常位于中心以下 5%–15%，上部靠线条延伸。

### 4.2 焦点系统

优先采用“1 主焦点 + 2 次焦点 + 若干肌理”的结构：

- 主焦点：一朵超尺度花，或 3–5 朵同类形成的集中块；
- 次焦点：在对角方向呼应，不与主焦点等大；
- 肌理层：苔藓、绣球、细叶、果实、穗材，用于连接空隙；
- 线条层：藤、枝、垂穗、铁丝，负责节奏和越界。

主花不要沿圆周均匀排列，也不要每种花各放一朵做“样品陈列”。

### 4.3 对称与节奏

- 骨架可近似对称，细节必须不对称；
- 用重复形成节奏，例如 3 个棒状花序、2 组同色百合、连续垂落穗材；
- 视觉节奏宜有疏密变化：密集核心、松散边缘、少量穿出；
- 至少保留一个负空间或暗部裂缝，避免所有空隙都被填满。

### 4.4 图形化处理

样本明显偏好可被一眼识别的几何母题：

- 大型百合、玫瑰、马蹄莲等作为星形、旋涡或喇叭形图形；
- 棕榈叶、龟背叶、纸张形成大平面；
- 针垫花、松果、球形果实提供点状节奏；
- 垂穗、藤条、细铁丝形成长线；
- 包装纸形成梯形、扇形或尖角色块。

选择花材时，优先考虑它在照片里的轮廓，不只考虑真实触感或花语。

## 5. 材料偏好与角色库

### 5.1 花材角色，而非固定清单

| 角色 | 视觉任务 | 偏好材料 | 可替换原则 |
| --- | --- | --- | --- |
| 主焦点 | 建立封面主图形 | 百合、玫瑰、马蹄莲、大丽花、帝王花、索拉花 | 保持尺寸、轮廓与表面光泽 |
| 体积 | 建立综合色块 | 绣球、苔藓、蓬松永生绿材、密集叶簇 | 保持块面面积和综合色相 |
| 结构 | 提供硬边与方向 | 银叶、棕榈片、龟背叶、喷色叶、枝条 | 保持硬度、宽度和走向 |
| 线条 | 拉高、越界、悬垂 | 藤条、垂穗、苋穗、芦苇、铁丝、细枝 | 保持长度与曲线节奏 |
| 颗粒 | 提升镜头细节 | 兔尾、针垫、果实、种荚、松果、蜡梅类小花 | 保持尺度对比和重复密度 |
| 高光 | 建立明暗反差 | 银色喷材、灰白花、透明膜、反光纸 | 保持反射或亮度，不必同材质 |
| 叙事物 | 对应专辑符号 | 蝴蝶、小模型、灯串、文字、特殊线条 | 每束 0–2 种，必须有出处 |

### 5.2 永生／仿真材料偏好

这套审美允许并鼓励使用非自然材料，因为它们更适合精确还原封面颜色和雕塑感：

- 染色永生绣球、永生苔藓、永生叶材；
- 索拉木花、仿真百合、仿真玫瑰；
- 喷漆叶片、金属色花材、局部手工上色；
- 干燥果实、种荚、松果、兔尾、芒草；
- 铁丝、透明线、细灯串；
- 哑光纸、皱纹纸、半透明硫酸纸、欧根纱、镭射膜。

染色必须服务于色盘，不追求“看起来像真花”。允许保留涂层、塑料或金属的人工质感。

### 5.3 鲜花模式

鲜花版不必机械复刻永生版，而应保留以下不可变项：

- 色彩比例；
- 主花轮廓；
- 高低关系；
- 包装色块；
- 强调色位置；
- 整体情绪。

替换优先级：**形态相似 > 色彩接近 > 花语相符 > 品种完全一致**。

### 5.4 表面质感配额

每束建议包含 3–5 类质感：

- 哑光 35%–55%；
- 绒毛／细碎 15%–30%；
- 光滑或蜡质 15%–30%；
- 半透明 5%–15%；
- 金属／反光 0%–10%。

同一种质感不要覆盖超过约 70%，除非设计目标是极端单一材质实验。

## 6. 包装与收口规则

### 6.1 包装层数

建议 2–4 个可辨认的大层，而不是大量细碎折边：

1. 后景主色板：面积最大，对应封面背景；
2. 中层过渡纸：半透明、灰色或邻近色；
3. 前层深色托底：收紧主体，增强对比；
4. 可选特殊材质层：金属、镭射、织物或手写纸。

### 6.2 包装形态

- 上沿保留宽阔平面与轻微弧线；
- 左右可不等高，但差异需要与花材方向一致；
- 尖角数量控制在 2–5 个；
- 不做层层外翻的“蛋糕裙”轮廓；
- 纸面允许褶皱，但褶皱应像材质纹理，不像运输挤压。

### 6.3 收口

- 默认使用窄丝带、透明带、纱带或麻绳；
- 绑结简洁，通常一个结或一组垂带即可；
- 丝带颜色取阴影色、包装同色或强调色，不另加新色；
- 垂带可作为构图长线，但不可遮挡主体花头。

## 7. 从专辑封面到花束的转译算法

### Step 1：读取视觉 DNA

为封面填写以下字段：

- 主色／支撑色／强调色；
- 整体明度：高调、中调、低调；
- 对比类型：明暗、冷暖、互补、材质、尺度；
- 主图形：圆、星形、块面、人物、线条、留白；
- 情绪词：限制为 3 个；
- 时代与媒介感：复古、数码、胶片、杂志、舞台、手工等。

### Step 2：选定唯一主命题

把视觉 DNA 压缩成一句设计命题，例如：

- “低温薄荷青中的水下漂浮感”；
- “粉色梦境里被压暗的黑色花体”；
- “高纯度红蓝对撞与孤立长线”；
- “苔藓森林中几乎被吞没的黑花”。

后续每个材料决定都要能解释它如何服务这句话。

### Step 3：建立四层结构

1. 背景层：包装与高位大叶；
2. 主体层：主花与体积花；
3. 肌理层：小花、果实、苔藓、细叶；
4. 线条层：枝、藤、垂穗、铁丝或灯串。

若某一层缺失，应是有意识的极简选择，而不是遗漏。

### Step 4：分配颜色与材料

每个颜色至少指定一种承载材料；每种材料必须承担一个角色。删除所有“只是觉得好看”但不服务色彩、结构或叙事的材料。

### Step 5：加入一个专辑符号

从封面或歌词中提取一个微型线索：蝴蝶、星点、火光、水纹、时间、人物剪影、特定植物等。优先抽象表达，避免把多个公仔堆成主题礼篮。

### Step 6：摄影校验

在黑色或极暗背景下，以正面略高视角拍摄。若缩小到手机缩略图后仍能读出主色、主花和轮廓，则结构成立。

| 情绪 | 色彩 | 形态 | 材质 | 灯光 |
| --- | --- | --- | --- | --- |
| 梦境／水下 | 青绿、灰蓝、冷白 | 松散、漂浮、长垂线 | 透明膜、纱、细绒 | 冷光、低对比边缘 |
| 夜晚／危险 | 黑、酒红、暗绿 | 收紧、尖锐、中心压暗 | 蜡质花瓣、喷色叶 | 高反差、局部高光 |
| 失恋／怀旧 | 褪粉、棕、灰蓝 | 纵向、轻微下垂 | 旧纸、干花、哑光表面 | 暖暗光、轻褪色 |
| 流行／青春 | 亮绿、粉、黄、青 | 大块、圆润、饱满 | 光滑花面、亮纸 | 正面亮光、色彩清晰 |
| 冷峻／工业 | 银、黑、灰白、钴蓝 | 硬边、几何、留白 | 金属纸、塑料、喷漆叶 | 冷硬定向光 |
| 森林／死亡记忆 | 苔绿、墨绿、羊皮纸、黑 | 野生、枝条外伸 | 苔藓、树枝、皱纹纸 | 低照度、局部湿润感 |
| 节庆／热烈 | 红、金、暖白、深绿 | 密集、向上、发光点状 | 果实、毛绒、灯串 | 暖光点缀 |

## 9. 摄影与成片规则

- 背景首选无缝黑布或暗色哑光背景，减少环境杂物；
- 镜头高度接近花束中上部，避免过度俯拍压扁轮廓；
- 主光从正侧上方进入，保留暗部，不追求全亮；
- 黑花必须有轮廓高光，否则会与背景融为一体；
- 金属和透明材料只允许局部反光，不可大面积过曝；
- 白平衡服从专辑情绪，可冷可暖，但中性色不应脏黄；
- 成片留出封面小图、标题或社媒界面的位置，但花束本身仍应完整成立；
- 后期可统一色相和压暗背景，不应把所有材质磨成同一塑料质感。

---

## 10. 禁止项

- 禁止用“花语”替代视觉分析；
- 禁止把封面五种颜色平均铺满；
- 禁止未经处理的大量自然绿抢占主色；
- 禁止所有花头朝正面、等间距排列；
- 禁止每个空隙都塞满配花；
- 禁止包装层数多而每层面积很小；
- 禁止同时出现三个以上无关装饰物；
- 禁止因为使用永生花而追求假装自然；
- 禁止只还原颜色，不还原明暗、轮廓和情绪；
- 禁止为了“高级”一律降饱和，强烈专辑应保留其高纯度与俗艳风险。

## 12. 设计验收清单

交付前逐项检查：

- [ ] 3 秒内能看出唯一主色世界；
- [ ] 至少存在一个明确色彩或材质冲突；
- [ ] 缩小为缩略图后，主焦点和轮廓依然清楚；
- [ ] 主花没有平均散布；
- [ ] 包装是构图色块，而非装饰边框；
- [ ] 至少有三类不同表面质感；
- [ ] 至少有一条越出主体边界的线性材料；
- [ ] 有一处负空间或深色裂缝；
- [ ] 自然绿的比例经过有意识控制；
- [ ] 强调色面积不超过约 10%；
- [ ] 专辑符号不超过两个，且有明确出处；
- [ ] 去掉封面参照后，花束仍具有独立完整性；
- [ ] 花艺师能够根据角色和替代条件实际制作；
- [ ] 摄影光线能分离黑色花材与黑色背景。

### 快速评分

每项 0–2 分，总分 20 分：

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 色彩层级 | 混乱平均 | 有主次但不稳定 | 主次鲜明且有回声 |
| 封面关联 | 仅同色 | 情绪或构图相似 | 色彩、构图、情绪均成立 |
| 轮廓 | 普通圆形 | 有方向但不清晰 | 缩略图可识别 |
| 焦点 | 无焦点 | 焦点较散 | 单一强焦点明确 |
| 材质 | 单一 | 有两类对比 | 软硬、明暗、透明度丰富 |
| 包装 | 被动包裹 | 颜色正确 | 主动参与版式 |
| 张力 | 甜美安全 | 有轻微冲突 | 冲突明确且受控 |
| 叙事 | 装饰堆砌 | 有一个线索 | 线索克制且准确 |
| 可制作性 | 无法落地 | 需大量猜测 | 配方与替代规则清楚 |
| 摄影表现 | 平、暗或杂乱 | 可读 | 舞台感强且层次完整 |

- 17–20：可作为系列主视觉；
- 13–16：方向成立，需强化焦点或删减材料；
- 9–12：更像常规配色花束，需要重做视觉命题；
- 0–8：尚未完成从封面到花束的设计转译。

## 13. 最小可行规则

当时间或预算有限时，至少守住以下六点：

1. 只用 3–4 个主要颜色，并明确比例；
2. 选择一朵图形感强的主花；
3. 用一块大包装色面还原封面背景；
4. 加入一种与主花相反的质感；
5. 保留一处不对称长线或垂线；
6. 在黑色／暗色背景下完成最终校验。

做到这六点，即使使用平价材料，也能保持这套审美的核心识别度。
